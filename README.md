# pokertab

pokertab is a windows desktop app that helps manage a tournament style poker game from start to finish.

the goal of pokertab is to make running a poker game easier. instead of having one person keep track of everything by hand, pokertab keeps track of the important information for the table.

## features

pokertab will include

* create and manage a poker tournament
* add players to a tournament
* record player buy ins
* record player rebuys
* keep track of the total prize pool
* keep track of active and eliminated players
* track player positions
* track and update poker blinds
* record final player placements
* calculate tournament payouts
* show the final results of the tournament
* save previous tournament information

## goal

our goal is to create a simple program that makes casual poker tournaments easier to manage. pokertab is mainly designed for college students, friends, and other groups who want to run poker games without having to keep track of everything by hand.
